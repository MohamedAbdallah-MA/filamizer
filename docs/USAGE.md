# Use the Filamizer editors

After [installing Filamizer](../README.md#quick-start), open **Dashboard appearance** to edit the shared dashboard or **My appearance** from the user menu to edit your own look.

## Change the shared theme

1. Open **Dashboard appearance** → **Dashboard Appearance & Design System**.
2. Under **Mode to edit**, choose **Light theme** or **Dark theme**.
3. Pick a **Starting palette**, then set **Skin**, **Main color**, and **Backdrop**. **Quick setup** shows these everyday controls. The **Preview** updates as you edit.
4. Switch to the other theme to edit its colors, skin, and backdrop separately. Text size and the global font and layout controls apply to both themes.
5. Click **Save changes** to apply the new defaults across the panel.

Use **Full customization** for detailed controls such as text and input colors, typography, and effects for the selected skin. For example, choose **Liquid Glass** to see tint, opacity, blur, and refraction. **Automatic readability** adjusts the rendered text and glass where needed and keeps your chosen values saved. Refraction appears in Chrome and Edge and is omitted from the miniature preview.

**Mode to edit** controls which theme you’re designing. To control which theme users see, go to **Full customization** → **Dark mode and personal looks**. **Dark Mode** lets you allow switching or enforce one mode. **Default Mode** sets the starting mode for users who haven’t chosen one.

## Arrange the sidebar

1. Open **Dashboard appearance** → **Sidebar**.
2. Click **Add group**, or drag a group by its handle to reorder it.
3. Drag items into groups or into **Without group (top of the sidebar)**.
4. Use an item’s **Edit** control to change its label and icon. The default setup supports English and Arabic labels. Use **Hide from sidebar** to remove a link from view.
5. Click **Save changes**, then check the panel sidebar.

**Reset to default** restores the host panel’s navigation in the editor. Save to apply it. Hiding links changes the menu only. The host application’s permissions still control access to pages and resources.

## Personalize your own dashboard

Open **My appearance** from the user menu, choose a mode, and adjust the available controls. Click **Save changes** to keep the look for your account. **Reset to default** followed by **Save changes** restores the shared appearance.

Administrators can choose which skins users can select under **Full customization** → **Dark mode and personal looks** → **Skins users can pick for themselves**. Clearing all skins hides **My appearance** and suspends the use of saved overrides across the application.

## Reuse a saved look

The **Profiles** section stores both light and dark appearance settings. Shared profiles are managed from **Dashboard appearance**. Personal profiles belong to the user who created them.

- **Save as profile** creates a named snapshot of the current editor settings. Saving again with the same name replaces that profile in the same scope.
- Click a profile card to load it into the editor. Click **Save changes** to apply the loaded settings to the dashboard.

In the current development build, **Save as profile** may fail to open its dialog. Use **Save changes** to keep the active look if the dialog does not open.
