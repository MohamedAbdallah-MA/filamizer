# Customizer interaction design

Quick setup presents presets, skin choices and a live preview. Full customization
reveals precise colors, typography, surfaces, effects and background controls.
Light and dark looks are edited independently. Keep shared and personal profiles
visible and preserve saved looks when switching presets or modes.

Show glass controls only where relevant. Solid backgrounds expose their color;
gradients expose their stops and direction; aurora exposes movement and speed;
image backgrounds expose their image setting. Keep the preview visible while
scrolling where screen space allows, and stack it on small screens.

Automatic glass readability should improve effective colors while preserving
user input. An explicit override permits exact custom colors. Check text,
placeholders, validation, active navigation icons, dates, popovers and focus states
in both directions and modes. These checks are acceptance criteria, not a claim
that every combination is already verified.
