# Filamizer promotional artwork

Created with the built-in image generation tool. These are conceptual product
illustrations, not application screenshots. Source PNGs are retained here.

Upload files:
- `filamizer-image-2560x1440.jpg`: main listing image, 16:9.
- `filamizer-thumbnail-1280x720.jpg`: separate landscape thumbnail, 16:9.

JPEGs are exported at quality 95. The main source is resampled to meet the
listing minimum resolution. See PROMPTS.md for generation instructions.
Marketing artwork is retained in Git but excluded from Composer archives.
